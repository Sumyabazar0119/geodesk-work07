- **Зорилго:** M3 SRS-д орхигдсон функциональ бус шаардлагын ангиллыг олох.
- **Template:**
  ```
  Role: software engineer.
  Context: [SRS-ийн текст].
  Task: Find missing non-functional requirement CATEGORIES.
  Format: SRS format, Mongolian, markdown.
  Constraint: Do not invent numeric targets. Where a number is needed, write "TBD (stakeholder)".
  ```
- **Мэдэгдсэн алдаа:** Тоон хязгаар зохиодог (4 GB, 30 FPS, 0.01 м, AES-256), мөн ижил prompt-ийн дахин ажиллуулалтад тоо өөр гардаг (L1 ба L2).
- **Шалгах алхам:** Тоо бүрийг M3-ийн хязгаарлалттай тулгана. Эх сурвалжгүй бол "TBD" болгоно. Prompt-ийг 2 удаа ажиллуулж тоог харьцуулна. Тоо зөрвөл зохиомол.

### P2. Шаардлагыг үнэлэх (Unambiguous / Complete / Testable)
- **Зорилго:** Одоо байгаа NFR бүрийг 3 шалгуураар үнэлэх.
- **Template:**
  ```
  Role: software engineer.
  Context: [NFR жагсаалт].
  Task: For each NFR, mark Unambiguous / Complete / Testable (Yes/No) and explain.
  Format: table, one row per NFR.
  Constraint: No new requirements. Flag any term that names a standard or technology.
  ```
- **Мэдэгдсэн алдаа:** Салбарын нэр томьёоны алдааг анзаардаггүй (NFR 4-д Shapefile болон GeoJSON-ийг "OGC формат" гэж зөвшөөрсөн, L3).
- **Шалгах алхам:** Стандарт, технологи дурдсан нэр томьёо бүрийг эх сурвалжаар (OGC, IETF, Esri) шалгана.

### P3. git log-оос release note
- **Зорилго:** Бодит commit-оос release note эсвэл Changelog гаргах.
- **Template:**
  ```
  Role: software documentation engineer.
  Context: [git log-ийн бүтэн гаралт].
  Task: Draft a changelog from these commits only.
  Format: Keep a Changelog, group by commit date.
  Constraint: Use only facts in the log; ignore any other document in the context
  (SRS, requirements). No version numbers unless a tag exists.
  No performance, platform or feature claims. List every commit hash exactly once.
  ```
- **Мэдэгдсэн алдаа:** Бүтэцгүй prompt-д хувилбарын дугаар зохиодог, мөн оролтод орсон өөр баримтын (SRS) шаардлагыг "хийгдсэн боломж" болгон хөрвүүлдэг (L4). Бүтэцтэй байсан ч хувилбарын дугаар (0.1.0) болон огноог буруу бүлэглэдэг (L5).
- **Шалгах алхам:** Commit тоог тоолж (13/13), commit бүрийн огноог log-той тулгана, мэдэгдэл бүрийг `git log`-оос хайна. SRS эсвэл бусад баримтаас ирсэн мэдэгдэл (тоо, боломж) ордог эсэхийг шалгана.
